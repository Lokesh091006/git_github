================================================================================
GIT WORKFLOW COMMAND DOCUMENTATION
Assignment: Git & GitHub Workflow Documentation
File: git_commands.txt
================================================================================

1. git init
   Initializes a new empty Git repository in the local project directory, creating the hidden .git metadata folder.

2. git status
   Displays the current state of the working directory and staging area, listing untracked, modified, and staged files.

3. git add index.html about.html
   Stages the specified HTML files to the staging area (index), preparing them to be included in the next commit.

4. git commit -m "Initial commit: Add index.html and about.html"
   Saves the staged snapshot of index.html and about.html permanently to the repository history with a descriptive message.

5. git add about.html
   Stages modifications made to the about.html file to prepare for the second project commit.

6. git commit -m "Update about.html: Add project mission and team details"
   Records the updated version of about.html into repository history as the second commit.

7. git branch feature
   Creates a new branch named 'feature' from the current HEAD commit, allowing isolated feature development.

8. git switch feature
   Switches the active working branch and HEAD pointer to the newly created 'feature' branch.

9. git add index.html
   Stages the updated index.html containing the new navigation bar and feature highlights on the feature branch.

10. git commit -m "Add responsive navigation bar and feature highlights on feature branch"
    Records the feature branch changes as an independent commit isolated from the main branch.

11. git switch main
    Switches the active branch back to the 'main' branch in preparation for integrating the feature branch.

12. git merge --no-ff feature -m "Merge feature branch into main"
    Merges commits from the 'feature' branch into 'main' using non-fast-forward mode to preserve distinct branch history.

13. git log --graph --oneline --all --decorate
    Displays a visual ASCII graph of the complete commit history across all branches with abbreviated hashes and branch tags.

14. git add .gitignore
    Stages the .gitignore file configured to exclude log files (*.log) and temporary directories (temp/).

15. git commit -m "Add .gitignore to ignore log files and temp directory"
    Commits the .gitignore configuration file so that ignore rules are version-controlled and shared across the team.

16. git reset --soft HEAD~1
    Undoes the most recent commit by moving the HEAD pointer back by one commit while keeping changes staged in the index.

17. git restore --staged draft.txt
    Unstages draft.txt from the staging area without discarding the file's modifications in the working tree.

18. git remote add origin https://github.com/lokeshsure668/git-workflow-assignment.git
    Connects the local Git repository to a remote repository hosted on GitHub under the alias 'origin'.

19. git push -u origin main
    Uploads the local 'main' branch commits to GitHub and configures the remote tracking branch for future pushes and pulls.

20. git push origin feature
    Pushes the 'feature' branch to GitHub to make the complete branch and merge history visible on the remote repository.
